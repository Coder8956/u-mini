# 管理器模块

## 说明
- 全局静态单例
- 用于管理功能模块的访问和生命周期

## 类名
- UMGR

## 功能

### 启动管理器
```
Launch();
```

### 注册模块
```
Register<T>();
```
- `T` 模块类型

### 初始化模块
```
InitModules(Action<InitProgressInfo> moduleInitInfoHandler)
```
- `moduleInitInfoHandler`模块初始化进度处理器

### 获取模块
```
Get<T>();
```
- `T` 模块类型
