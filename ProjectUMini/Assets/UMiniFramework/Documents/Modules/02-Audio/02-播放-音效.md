# 播放音效

## 说明
- 管理音效播放
- 每个音效使用一个 AudioSource 播放.全局根据情况会有多个音效 AudioSource

## 类名
- UMAudioEffect

## 功能

### 播放
```
Play(string id)
```
- `id`音效id

### 添加音频片段
```
void AddAudioClip(UMAudioClipInfo aci)
```
- `aci`音频模块信息

### 在控制台输出 AudioSource 相关信息
```
PrintASInfo()
```

## 属性

### Mute
- 控制是否静音

### Volume
- 控制音量
