# 本地化模块

## 说明
- 管理本地化

## 类名
- UMLocal

## 功能

### 设置本地化字典
```
SetLocalDic(Dictionary<string, Dictionary<string, string>> dic)
```
- `dic`本地化字典([localization,[local_id,value]])

### 切换本地化
```
SwitchLocal(string local)
```
- `local`本地化key

## 属性

### 当前本地化
- `CurtLocal`
