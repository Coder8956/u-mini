# 配置模块

## 说明
- 管理游戏相关配置
- 输入文件是 Excel
- 输出文件是 Json
- 生成的数据表命名 `excel文件名 + Table`
- 生成的数据命名 `excel文件名 + Data`
- 在框架启动时要先将需要使用的配置表进行注册
    - 例如
    ```
    UMConfigInitArgs umConfigInitArgs = new UMConfigInitArgs();
    umConfigInitArgs.ConfigTables.Add(new LevelTable());
    UMGR.Register<UMConfig>(umConfigInitArgs);
    ```

## 类名
- UMConfig

## 功能

### 获取配置表
```
T GetTable<T>()
```
- `T`配置表类型

## 初始化参数

### 类名
- UMConfigInitArgs

### 属性

#### LoadConfigHandler
- 用于处理加载配置的具体操作
- 模块已经定义的处理器
    - `UMResLoadConfigHandler`从Unity Resources文件夹加载配置
- 支持自定义扩展
    - 扩展接口`IUMLoadConfigHandler`

#### ConfigTables
- 所有需要使用的配置表

## 自定义扩展

### 编写Excel配置
- [Excel模板](./Assets/excel-config-template.xlsx)
    - 第一行写 **字段注释**
    - 第二行写 **字段名**
    - 第三行写 **字段类型(id字段只支持 string)** 支持以下类型的数据
        - float
        - string
        - int
        - bool
        - 数组 **数组值用`;`分割**
            - float[] 
            - string[]
            - int[]
            - bool[]
