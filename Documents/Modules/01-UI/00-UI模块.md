# UI模块

## 说明
- 管理UI界面

## 类名
- UMUI

## 功能

### 创建界面
```
UMGR.Get<UMUI>().Create<T>();
```
- `T` UI类型

### 销毁界面
```
UMGR.Get<UMUI>().Destroy(panel);
```
- `panel` UI对象实例

### 打开界面
```
UMGR.Get<UMUI>().Open(panel, layerIndex);
```
- `panel` UI对象实例
- `layerIndex` 层级索引

### 关闭界面
```
UMGR.Get<UMUI>().Close(panel);
```
- `panel` UI对象实例
