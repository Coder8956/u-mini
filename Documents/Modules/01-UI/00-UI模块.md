# UI模块

## 说明
- 管理UI界面

## 类名
- UMUI

## 功能

### 创建界面
```
Create<T>();
```
- `T` UI类型

### 销毁界面
```
Destroy(panel);
```
- `panel` UI对象实例

### 打开界面
```
Open(panel, layerIndex);
```
- `panel` UI对象实例
- `layerIndex` 层级索引

### 关闭界面
```
Close(panel);
```
- `panel` UI对象实例

### 在控制台输出所有创建的界面
```
DumpCreatedUI()
```

### 判断是否点击了UI
```
IsClickUI()
```

## 属性

### TopLayerIndex
- 获取最顶层 Layer Index

## 初始化参数

### 类名
- UMUIInitArgs

### 属性

#### IsCreateEventSystem
- 是否需要创建事件系统

#### UILayerCount
- 需要创建多少个UI层级

#### Canvas
- UI根 Canvas
