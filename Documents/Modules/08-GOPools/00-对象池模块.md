# 对象池模块

## 说明
- 管理游戏内需要重复创建的对象

## 类名
- UMGOPools

## 功能

### 创建对象池
```
UMGOP CreatePool(string poolTag, GameObject prototype, int initObjectCount = PoolInitObjectCount)
```
- `poolTag`对象池标记
- `prototype`对象原型
- `initObjectCount`对象初始化数量
- `UMGOP`对象池返回值

### 获取对象池
```
UMGOP GetPool(string poolTag)
```
- `poolTag`对象池标记
- `UMGOP`对象池返回值

### 销毁对象池
```
void DestroyPool(string poolTag)
```
- `poolTag`对象池标记
