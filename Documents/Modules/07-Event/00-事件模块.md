# 事件模块

## 说明
- 管理游戏事件

## 类名
- UMEvent

## 功能

### 发送事件
```
void Dispatch(string eventTag, UMBaseEventContent content = null)
```
- `eventTag`事件标记
- `content`事件内容默认为null.

### 添加侦听器
```
void AddListener(UMEventListener listener)
```
- `listener`事件侦听器

### 移除指定Tag的所有侦听器
```
void RemoveAllListenerByEvnetTag(string eventTag)
```
- `eventTag`事件标记

### 移除侦听器
```
void RemoveListener(UMEventListener listener)
```
- `listener`事件侦听器

### 移除所有侦听器
```
void RemoveAllListener()
```
