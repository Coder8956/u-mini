# 数据持久化模块

## 说明
- 管理数据持久化

## 类名
- UMDataPer

## 功能

### 存数据
```
Save(key, val)
```
- `key`数据key值
- `val`具体数据

### 读数据
```
Read(key, defaultVal)
```
- `key`数据key值
- `defaultVal`数据默认值

### 删除指定数据
```
Delete(key)
```
- `key`数据key值

### 删除所有数据
```
DeleteAll()
```

## 扩展
- 可以继承`IUMDataPerHandler`接口,实现自定义数据持久化功能
