# 数据持久化模块

## 说明
- 管理数据持久化

## 类名
- UMDataPer

## 功能

### 存数据
```
Save(key, val)
```
- `key`数据key值
- `val`具体数据

### 读数据
```
Read(key, defaultVal)
```
- `key`数据key值
- `defaultVal`数据默认值

### 删除指定数据
```
Delete(key)
```
- `key`数据key值

### 删除所有数据
```
DeleteAll()
```

## 初始化参数

### 类名
- UMDataPerInitArgs

### 属性

#### DataPerHandler
- 用于处理数据持久化的具体操作, 需要持久化的数据最终都会转换成字符串
- 模块已经定义的处理器
    - `UMDataJsonFileHandler`用json文件持久化数据
    - `UMDataUnityPrefsHandler`用UnityEngine.PlayerPrefs持久化数据
- 支持自定义扩展
    - 扩展接口`IUMDataPerHandler`
